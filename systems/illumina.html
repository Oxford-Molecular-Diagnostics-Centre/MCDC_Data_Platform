Sequencing infrastructure

Illumina cloud ecosystem

BaseSpace Sequence Hub, Illumina Connected Analytics and Connected Insights are options for sequencing-related data and analysis workflows.

← All systems

What the system supports

  • Review sequencing run information through configured BaseSpace access.
  • Use project-appropriate cloud analysis capabilities.
  • Connect sequencing outputs with downstream QC and review workflows.
  • Agree platform access and data delivery with the project team.

A typical workflow

  1. Generate sequencing data using the agreed instrument workflow.
  2. Review run information and choose the configured analysis route.
  3. Deliver outputs for downstream QC, interpretation and reporting.

Outputs

Sequencing run information and analysis outputs from the selected service.

Scope and availability

The WebNGS documentation supports a configured BaseSpace connection. ICA and ICI are capabilities named in the source overview; their use and integrations must be confirmed for the project.

Access, configuration and validation requirements are agreed with the project and laboratory teams for the intended use.
