Sequencing workflows

WebNGS

The sequencing dashboard brings run planning, sample sheets, BaseSpace run information, QC and analysis tasks into a project-oriented workflow.

← All systems

What the system supports

  • Plan sequencing runs and generate sample sheets using configured index and project rules.
  • Review BaseSpace sequencing runs and QC dashboards.
  • Queue QC and analysis pipelines for separate Nextflow workers.
  • Browse analysis outputs and prepare project-specific reporting assets.
  • Use sample tracking and read-only LIMS views where configured.

A typical workflow

  1. Select the project, prepare samples and download the run sample sheet.
  2. Review sequencing status and queue the required QC or analysis jobs.
  3. Inspect results, quality metrics and reporting outputs.

Outputs

Run sample sheets, QC summaries, pipeline task history and configured analysis or reporting outputs.

Scope and availability

Pipeline execution requires configured workers, storage and project settings. Reporting and interpretation features include project-specific behaviour; availability must be agreed for each study.

Access, configuration and validation requirements are agreed with the project and laboratory teams for the intended use.
