Genomic review

WebIGV & reporting

Browser-based genomic review supports inspection of sequencing alignments alongside project-specific reporting workflows.

← All systems

What the system supports

  • View sequencing data with the IGV.js genome browser.
  • Review alignment tracks and genomic regions relevant to the analysis.
  • Retrieve authorised data and reporting assets from project storage.
  • Support project-specific report generation alongside the WebNGS reporting workflow.

A typical workflow

  1. Select the authorised project data and analysis results.
  2. Inspect relevant alignments and variants in the genome browser.
  3. Prepare the agreed report or hand over findings for review.

Outputs

Interactive genomic views and project-specific report outputs.

Scope and availability

The supplied screenshot shows a WebNGS interpretation view. The separate WebIGV repository provides an authenticated IGV.js application; the two interfaces should not be assumed to have identical features. Interpretation and reports require the appropriate study and assay review.

Access, configuration and validation requirements are agreed with the project and laboratory teams for the intended use.
